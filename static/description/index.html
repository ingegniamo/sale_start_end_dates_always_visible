Sale Start End Dates Always Visible

Extension of the OCA module sale_start_end_dates: the date fields of the sale order lines are always visible.

Features

Start date, end date and number of days are shown on the order lines list of the sales order form and on the read-only order line form, also for products that do not require dates. They stay required only when the product requires dates.
